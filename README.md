# Salabim Learning

My journey learning discrete-event simulation using Python and Salabim.

## Topics Covered

- Basic simulation concepts
- Components and environments
- Queues and resources
- States and events
- Monitors
- Animation
- Practical simulation problems

## Setup

Create a virtual environment:

    python -m venv env
    source env/bin/activate

Install dependencies:

    pip install -r requirements.txt

## Running Examples

    python basic.py
